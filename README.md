# BookStore — Landing Page da Autora

Landing page single-page para uma escritora, com foco em leitura e visual limpo.

## Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- TypeScript
- Tailwind CSS v4
- Radix UI

## Seções

- Hero com foto (placeholder) e biografia
- Novidades
- Lista de obras, com botão de compra via WhatsApp
- Rodapé com contatos e modal "Apoiar a autora" (QR Code via Radix Dialog)

## Rodando localmente

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```
